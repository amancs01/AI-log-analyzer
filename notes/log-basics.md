# Log Basics

## What is a log?
A log is a record of events that happen inside a system, application, server, or network.

## Why logs are important in cybersecurity
Logs help security teams find suspicious activity such as failed login attempts, unauthorized access, malware detection, port scanning, and brute force attacks.

## Basic parts of a log
- Timestamp: shows when the event happened.
- Log level: shows the seriousness of the event.
- Event/message: explains what happened.
- IP address: shows where the activity came from.
- Username: shows which user was involved.

## Common log levels
- INFO: normal activity.
- WARNING: unusual activity that may need attention.
- ERROR: failed or blocked activity.
- ALERT: serious security issue.

## Normal log examples
- User logged in successfully.
- System backup completed.
- Security scan completed.

## Suspicious log examples
- Failed login attempt.
- Unauthorized access attempt.
- Port scan detected.
- Malware signature detected.
- Possible brute force attack.

## Key lesson
Logs are the raw evidence used by security tools. A log analyzer reads log lines, finds suspicious patterns, and helps estimate risk.
